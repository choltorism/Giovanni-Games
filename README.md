# Giovanni Games — نسخهٔ اولیه

این پوشه نسخهٔ اولیه و قابل تست سایت بازی‌های کافه جیووانی است.

## فایل‌ها
- `index.html`: صفحه و متن‌ها
- `style.css`: ظاهر موبایل‌پسند
- `app.js`: پنج بازی قابل اجرا

## نکتهٔ مهم
این نسخه فقط مرحلهٔ اول است: ورود اسم، منوی بازی‌ها و بازی‌های آزمایشی. **هنوز جایزهٔ واقعی، کد تخفیف یکتا، ذخیره‌سازی سروری یا محدودیت ۱۲ ساعته بر اساس IP ندارد.** برای جلوگیری از دور زدن محدودیت، این موارد باید در مرحلهٔ بعد سمت سرور و پایگاه داده پیاده شوند.
